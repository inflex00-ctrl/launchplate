Before you buy

Reasonable
questions.

The demos are free and complete. If anything below still matters to you after clicking through them, the refund window exists for exactly that reason.

Is the demo the same thing I am buying?

Yes. The live demo is the kit, running. The ZIP contains those exact files — the same 6 pages, the same stylesheet, the same JavaScript — with the placeholder copy still in place for you to replace.

Do I need a framework, npm or a build step?

No. It is HTML, one CSS file and a little vanilla JavaScript. There is no package.json and nothing to install. Open the folder, edit the text, upload it to Netlify, Vercel, GitHub Pages, Cloudflare Pages or any host that serves files.

Can I use this for a paying client?

Yes. Unlimited commercial projects are included, client work explicitly among them, with no extra licence per site or per client. The only restriction is that you cannot resell the kit itself as a template.

How hard is it to rebrand?

The stylesheet opens with a block of CSS custom properties — background, surface, text, accent, radius, font stack. Change those and the whole kit follows, both themes included. No compilation, no watch process, just save and refresh.

How is it delivered?

Stripe takes the payment and you land straight on a download page with your files. The same permanent link is on your receipt. There is no account to create and no password to forget.

What if I do not like it?

Reply to your Stripe receipt within 14 days and you get a full refund. No form, no explanation required and no follow-up questions.
